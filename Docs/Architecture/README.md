## 三句话概括这套架构

1. **数据用 ScriptableObject（`XxxDefinition`），运行时用普通 C# 类（`XxxInstance`）**，两者绝不混用。
2. **效果用 `[SerializeReference]` 多态类**，14 个通用效果类覆盖 90% 需求，加一张卡不用写代码。
3. **逻辑同步执行、表现异步排队**：`BattleContext` 里跑完整场战斗不需要任何 UI，`BattlePresenter` 从事件队列取动画播。

## 从哪开始

先读 [01](01-架构总览与目录.md) 的 2.1 十条原则和 2.3 依赖图，再读 [03](03-核心代码.md) 的 5.16 `BattleContext` 和 5.18 `BattleController`。这两个类是整套架构的骨架。

然后按 [06](06-开发路线图与风险检查.md) 的第 1 阶段动手，24 个类做出一个能打死史莱姆的战斗。
